# Tabela FIPE copiada sob demanda para o nosso banco

Marca, modelo, versão e a referência de preço dos veículos (spec 005) vêm da API pública gratuita da FIPE (Parallelum, não oficial), mas o app só lê do nosso banco (`fipe_brands`, `fipe_models`, `fipe_years`, `fipe_prices`). A cópia é feita sob demanda: a primeira vez que uma lista ou um preço é pedido, o servidor busca na API e guarda; listas valem 30 dias e o preço vale o mês de referência, depois são renovados no uso. A API gratuita aceita 500 consultas por dia (cabeçalho `x-ratelimit-limit`), e a tabela inteira tem dezenas de milhares de versões, então copiar tudo de uma vez não cabe na cota. Se a API cair ou mudar, o que já foi guardado continua valendo e o formulário funciona; só deixa de atualizar. O veículo guarda também os nomes da FIPE, para não depender da cópia nem da API depois de cadastrado. Trocar de fonte (API paga, oficial) muda só `src/platform/fipe/client.ts`.
