# Imagens no Cloudinary, não no storage do banco

Todas as fotos (veículos, logo e capa da loja) vão para o Cloudinary, com upload assinado pelo servidor e enviado direto do navegador. O plano gratuito do Cloudinary já entrega redimensionamento, formatos modernos e CDN, que no Supabase Storage exigiriam plano pago ou código próprio.
