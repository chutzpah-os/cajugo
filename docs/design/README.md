# CajuGo — Design do MVP

## Conteúdo
- `CajuGo Telas.dc.html` — todas as telas (mobile, 390 px) num canvas navegável. Abra no navegador (precisa de internet para as fontes). Ids como 1a, 2a, 6c identificam cada tela nos documentos. Precisa do `support.js` na mesma pasta.
- `telas/` — capturas de cada tela, agrupadas por fluxo.
- `carexamplesimages/` — fotos ilustrativas de veículos usadas nas telas e úteis como dados de exemplo (seed).
- `DESIGN.md` — sistema visual (cores, tipografia, componentes), padrões de UX, detalhe de cada tela e microcopy.
- Requisitos de produto: `../PRD.md`.
